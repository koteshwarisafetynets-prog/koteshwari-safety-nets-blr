# Koteshwari Safety Nets - Official Website

High-performance Next.js 16 (Turbopack) production website for **Koteshwari Safety Nets** — serving residential, commercial, and industrial clients across Bangalore, Karnataka.

## 🛠 Tech Stack
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **SEO**: Dynamic Sitemap, Semantic JSON-LD (LocalBusiness, Service, FAQPage, BreadcrumbList)
